# PRODIGY_ML_05
task5 in machine learning

## Objective
Develop a CNN model that recognizes food items from images and estimates their approximate calorie content.

## Dataset
Custom Food Dataset with five food categories:
- Pizza
- Burger
- Apple
- Banana
- Sandwich

## Technologies Used
- Python
- TensorFlow
- NumPy
- OpenCV
- Matplotlib

## Workflow
- Load image dataset
- Preprocess images
- Train CNN model
- Evaluate model
- Predict food category
- Estimate calories using predefined calorie values

## Sample Calories

| Food | Calories |
|------|----------|
| Pizza | 285 kcal |
| Burger | 295 kcal |
| Apple | 95 kcal |
| Banana | 105 kcal |
| Sandwich | 250 kcal |

## Result
The model predicts the food item and displays its estimated calorie content
